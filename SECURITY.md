# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 0.x (latest) | Yes |
| older | No |

## Reporting a Vulnerability

Report vulnerabilities via [GitHub Security Advisories](https://github.com/remeic/ccm/security/advisories/new).

Do not open public issues for security vulnerabilities.

You can expect an initial response within 72 hours. If confirmed, a fix will be prioritized and released as soon as possible.
